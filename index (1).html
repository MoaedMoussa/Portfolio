PathForge Academy

React, TypeScript, Vite, Express, Drizzle ORM, Zod, Firebase

An interactive learning platform that makes algorithms visible. Learners watch pathfinding algorithms run on grids and levels that are generated on the spot.

  • TypeScript monorepo: React/Vite client, Express API, a shared Zod contract and a Drizzle schema, so client and server agree on types.
  • 6 pathfinding algorithms (A*, Dijkstra, BFS, bidirectional BFS, greedy BFS, DFS) and 3 procedural level generators (BSP, cellular automata, DFS maze).
  • Engine correctness is covered by 81 Vitest unit tests.
  • A 25-topic interactive CS curriculum built into the product.

Norra Scores

An ad-free live sports app. It started with football and grew to six sports, and installs on a phone like a native app.
